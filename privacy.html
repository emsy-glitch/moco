Kebijakan Privasi

Terakhir diperbarui: 24 November 2026 · Berlaku untuk website Moco (customer & admin).

Isi halaman Data yang dikumpulkan Tujuan penggunaan Penggunaan WhatsApp Penyimpanan lokal Berbagi data Hak pelanggan Keamanan & batasan Kontak

1. Data yang dikumpulkan

Moco hanya memproses data yang diperlukan untuk menampilkan menu dan melanjutkan pesanan:

  • Data keranjang — produk yang dipilih dan jumlahnya. Disimpan di browser kamu (LocalStorage), bukan di server.
  • Data pesanan — ID pesanan, tanggal, nama produk, jumlah, harga, total, dan status. Dibuat saat kamu menekan Checkout.
  • Data kontak — nomor WhatsApp dan username Instagram toko yang ditampilkan di website. Ini data toko, bukan data pribadi pelanggan.
  • Informasi yang kamu kirim lewat WhatsApp — nama, alamat, dan detail pembayaran yang kamu tulis sendiri saat melanjutkan transaksi di aplikasi WhatsApp.

Website ini tidak meminta pelanggan membuat akun, tidak mengumpulkan tanggal lahir, dan tidak menyimpan data pembayaran di browser.

2. Tujuan penggunaan data

  • Menampilkan isi keranjang dan menghitung total pesanan.
  • Mencatat pesanan agar admin dapat melihat dan memperbarui statusnya.
  • Membuat pesan pesanan otomatis saat kamu melanjutkan ke WhatsApp.
  • Menampilkan informasi kontak toko yang benar di halaman Contact dan Footer.

Data tidak digunakan untuk iklan bertarget, profiling, atau dijual kepada pihak lain.

3. Penggunaan WhatsApp

Checkout tidak memproses pembayaran di website. Website mencatat pesanan secara lokal, lalu membuka tautan wa.me berisi ringkasan pesanan (produk, jumlah, harga, total, dan ID pesanan) menuju WhatsApp penjual di 0812 8311 5852.

Setelah kamu berada di WhatsApp, pemrosesan pesan dan data lain mengikuti kebijakan privasi WhatsApp/Meta. Moco hanya menggunakan data tersebut untuk mengonfirmasi pesanan, pembayaran, dan pengiriman.

4. Penyimpanan lokal (LocalStorage)

Versi prototype ini menyimpan produk, keranjang, pesanan, kontak, dan log aktivitas admin di LocalStorage browser. Artinya:

  • Data hanya ada di perangkat/browser yang kamu gunakan dan tidak dikirim ke server.
  • Data tetap ada setelah halaman di-refresh, tetapi hilang jika kamu menghapus data situs atau memakai mode privat.
  • Data keranjang dan pesanan pelanggan dapat dibaca oleh siapa pun yang menggunakan browser yang sama.

5. Berbagi data

Moco tidak menjual atau membagikan data pelanggan. Data hanya diteruskan ke penjual melalui WhatsApp untuk menyelesaikan pesanan, atau diungkapkan jika diwajibkan hukum yang berlaku.

Website memuat font dari Google Fonts, sehingga browser melakukan koneksi ke server Google. Moco tidak mengirim data pesanan ke Google. Tidak ada analytics, cookie iklan, atau pixel pelacak di website ini.

6. Hak pelanggan

  • Menghapus data lokal dengan menghapus data situs di pengaturan browser.
  • Meminta informasi atau penghapusan data pesanan dengan menghubungi penjual.
  • Memilih untuk tidak melanjutkan pesanan sebelum menekan Checkout.

7. Keamanan dan batasannya

Admin Dashboard menerapkan password ter-hash (PBKDF2-SHA256 dengan salt), verifikasi dua langkah berbasis TOTP, pembatasan percobaan login, sesi 30 menit, validasi input, escaping output, dan log aktivitas lokal.

Penting: website ini masih berupa prototipe front-end tanpa backend. Hash password, secret MFA, penghitung percobaan, dan sesi berada di browser sehingga dapat dibaca atau dilewati oleh orang yang menguasai perangkat atau DevTools. LocalStorage juga dapat diubah manual. Karena itu website ini belum aman untuk produksi sampai autentikasi, rate limiting, sesi, database, dan log dipindahkan ke backend dengan HTTPS/TLS. Rincian ada di SECURITY.md pada repository.

Saat dipublikasikan, website harus diakses melalui HTTPS. Preview pengembangan sudah menggunakan HTTPS, tetapi konfigurasi TLS/HSTS produksi adalah tanggung jawab penyedia hosting/server.
